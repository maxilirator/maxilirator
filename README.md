# Mattias Geisler

Full-stack developer in Örebro, Sweden. I build systems where language models
do real work in business-critical flows, and where the output can be trusted.

### What I'm working on

- **Document interpretation at [docTech](https://doctech.nu)**: the parser that all
  document interpretation in the organization runs through. Qwen3-VL served locally
  with vLLM behind an OpenAI-compatible API, with schema validation, rules for
  financial documents and human verification.
- **Webbväg 2**: a platform for Swedish joint property associations
  (samfällighetsföreningar) covering property register, member portal, annual
  meetings, billing and bookkeeping. Nuxt/Vue and Frappe/ERPNext, integrated with
  Lantmäteriet's APIs and GIS. Business rules become code and tests with traceable rule IDs.
- **[ERPNext Sweden](LINK)**: open-source Swedish bank integrations for ERPNext.
  camt.053 and BgMax import, pain.001 payment export and payment reference validation.
